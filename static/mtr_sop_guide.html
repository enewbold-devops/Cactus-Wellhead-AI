  • Test parameter name and value

§4 — CMS-to-Approved-Process Crosswalk

Narrative details and process code summary table for each CMS specification

Scope: Foundational material requirements applied to all forgings, tubulars, bars, and mill shapes procured for pressure-bearing components. Always active.

Mandatory Process Codes

  • LAB-001 — accredited lab for chemistry, tensile, Charpy, hardness
  • CHT-GEN — general heat treat supplier capability

Conditional Codes (per PO/EPS)

  • CNT-002, CNT-003, CNT-004, CNT-005, CNT-007 — NDT method as flowed
📌
SOP Note: CMS-002 takes precedence over any conflicting requirement in a material-specific CMS. CMS-002-1 applies specifically to API 6A PSL-3 75K yield bodies over 1,000 lbs during heat treating.

Scope: Charpy test parameters, sub-size correlation rules, and acceptance logic. Applied with CMS-002 and material-specific CMS whenever Charpy is required by PO or EPS.

Mandatory Process Codes

  • LAB-001 — must be explicitly scoped for CVN impact testing
⚠
SOP Note: Do NOT assume LAB-001 approval for tensile testing automatically covers Charpy. Verify impact testing capability is explicitly listed in the approved scope for the specific lab site.

Scope: Requirements for AISI 4140 class — typically the most common material family in pressure-control forgings. Tight chemistry and HT window controls.

Required MTR Evidence

  • Chemistry vs. CMS-107 element tables
  • Q&T route actuals (austenitize/quench/temper temps, soak, quench media)
  • Tensile + impact + hardness results
  • HT furnace record reference
📌
SOP Note: Hardness caps apply. For sour-service (NACE/ISO 15156) flowdowns, validate maximum hardness limits against NACE tables in addition to CMS-107 limits.

Scope: Requirements for AISI 4340 class — higher hardenability than 4140. More sensitive to section size and quench media control.

Required MTR Evidence

  • Chemistry, HT window actuals
  • Tensile / impact / hardness
  • Heat / lot traceability
📌
SOP Note: Confirm HT supplier approval is at the site level — heavy section 4340 quench capability is site-specific. Company-level approval alone is insufficient.

Scope: Requirements for 17-4PH (UNS S17400) including corrosion-resistant and NACE-compliant aging condition routes.

Required MTR Evidence

  • Full chemistry including Cu and Nb/Cb
  • Ferrite / microstructure evaluation (where required)
  • Aging condition actuals (H900/H1025/H1150-M etc.)
  • Hardness (method + limits), traceability
⚠
SOP Note: Validate the aging condition on the MTR matches the PO/EPS requirement exactly. For NACE route: verify hardness cap compliance and modified chemistry limits. Ferrite and delta ferrite controls may be required — confirm LAB-001 microscopy and metallography scope at the site level.

Scope: Requirements for UNS N07718 (Alloy 718) following API 6ACRA requirements for CRA pressure-control equipment. Highest-scrutiny spec in the CMS suite.

Required MTR Evidence

  • Full chemistry (Nb, Mo, Ti, Al trace elements included)
  • Charpy impact results, hardness (method, location, limits)
  • Heat treat route actuals (solution anneal + double age temps and soak times)
  • Macroetch evaluation, microstructure phase examination (deleterious phase check)
  • API 6ACRA traceability artifacts
🔴
SOP Note: Confirm LAB-001 scope explicitly covers: ASTM A604 (macroetch), ASTM E1181 (grain size), metallography, and phase evaluation. Standard mechanical lab scope does NOT cover these.

API 6ACRA traceability chain must be unbroken from melt source through finished forging form.
Verify CHT-GEN and CNT-005 are not single-source for this material route.

Scope: Coating and plating process requirements when specified by PO or EPS. Only activated for parts with an explicit coating or plating requirement.

  • Mandatory codes: CCS-608, CCS-609, CCS-610, CCS-612, CST-800, CST-801, CST-811
  • Required evidence: coating/plating process certs, thickness measurements, process parameters, lot traceability to part/PO line
⚠
SOP Note: CCS-612 and CST-811 are flagged as single-source — require risk review before acceptance. Any sub-tier used for outsourced coating/plating must also appear in the Cactus approved provider list.

§5 — Key Risks Identified

Five risks requiring immediate action or standing watch items

⚠
These risks were identified during SOP analysis. Each must be tracked in Quality risk register and assigned an owner.
1

Incomplete Address Records in Approved Provider List

Multiple provider entries are flagged "ADDRESS NEEDS MANUAL REVIEW." These cannot be validated at the site level until address data is confirmed.

→ Recommendation: Quarantine these records. Do not auto-approve provider matches against entries without a verified site address until manual review is complete.

2

Single-Source Process Risks

The following process codes have only a single approved provider:

CCS-612 Coating   CHT-100 Heat Treat (specific capability)   CST-811 Surface Treatment   CNT-007 NDT Method

→ Recommendation: Any order requiring these services must trigger a supply chain risk review. Initiate a second-source qualification plan for each.

3

Company-Level vs. Site-Level Approval Gaps

Parent-company HT delegations exist in the approved provider list. The SOP must enforce that approval is validated at the individual operating site (street address + city), not assumed from a corporate parent entry.

→ Especially critical for CHT-GEN (heat treat) and LAB-001 (testing lab).

4

Lab Scope Coverage Gaps (CMS-303 & CMS-305)

LAB-001 approval may be granted for standard mechanical testing (tensile/Charpy/hardness) without explicitly covering:

  • Macroetch (ASTM A604)
  • Grain size (ASTM E1181)
  • Metallographic phase evaluation (deleterious phase detection)

→ Required by CMS-305 and conditionally by CMS-303. Confirm scope certificate before routing Alloy 718 or 17-4PH NACE MTRs to any lab.

5

Missing Provider Match ≠ Auto-Reject

If a provider cannot be matched to the approved list, the correct action is to route to "Needs Review" (Quality hold), not an automatic rejection. The provider may be legitimately approved under a different record or may require a one-time qualification for the specific scope.

→ Ensure the MTR intake system routes unmatched providers to a Quality Engineer review queue rather than triggering an automatic rejection.

§6 — SOP Enforcement Rules

Eight binding rules governing every MTR validation event

RULE 1
Provider match is required at the site level. Required match fields: supplier_name + site address/city + process_code + approval_status = ACTIVE. Company name + process code alone is NOT sufficient.
RULE 2
"ADDRESS NEEDS MANUAL REVIEW" entries trigger Quality hold. No MTR can be auto-accepted against a provider record with this flag active. Route to Quality Engineer for manual address verification before disposition.
RULE 3
"SINGLE SOURCE — risk review required" entries trigger risk queue. Add risk review step before final acceptance. Document risk review outcome in MTR Validation Case record.
RULE 4
Test method present but provider code missing or mismatched. Disposition = "Conditional / Needs Review." Quality Engineer to resolve before final disposition.
RULE 5
All accepted cases must be locked to: CMS spec + revision + applicability date  ·  Approved provider record ID(s)  ·  Heat/lot number + PO line item  ·  Disposition outcome + dispositioner + disposition date.
RULE 6
No silent changes. Any change to material, source, process, or test result after PO placement requires a formal SDR (Supplier Deviation Request) or EPS waiver with documented Quality disposition.
RULE 7
CMS-002 always applies. For any forging or wrought material purchase, CMS-002 is the floor. CMS-004 is applied whenever Charpy is required. Material-specific CMS (107/118/303/305) layers on top. Conflicts resolve to CMS-002.
RULE 8
Approved sub-tier traceability for outsourced processes. If a primary supplier outsources any process (heat treat, coating, NDT, lab testing) to a sub-tier, that sub-tier must appear in the Cactus approved provider list under the applicable process code and site.
