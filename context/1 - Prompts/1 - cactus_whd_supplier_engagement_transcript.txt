Understood — this is where pressure-control manufacturing QA lives: translating customer engineering requirements into controlled material/HT/testing plans.

## 1) Start with the governing envelope
- API 6A/ISO 10423 material class, temperature class, PSL/PR
- Sour service controls (NACE MR0175 / ISO 15156)

## 2) Chemical composition
Best practice: base spec + purchasing spec, CMTR traceability, sour-service gates.

## 3) Mechanical properties
Define YS/UTS/elongation and test orientation/temperature; reference accepted methods (e.g., ASTM A370 practices).

## 4) Charpy impact (CVN)
Lock down: method, temperature, specimen size, orientation/location, acceptance criteria, sampling frequency.

## 5) Heat treatment parameters
Create a Heat Treat Procedure (HTP): temp ranges, soak rules, quench media, temper windows, re-HT limits, furnace controls; link to hardness/CVN outputs.

## 6) Hardness testing rules
Specify scale, location plan, method, frequency, retest rules; note sour-service hardness caps.

## 7) Customer-facing compliance datasheet template
Service/design basis; material; mechanical; toughness; heat treat; hardness; traceability.
